# Baphalali Red Cross Eswatini
## Linux System Administration Project

Project Overview

This project demonstrates the implementation of a Linux-based system administration environment for Baphalali Red Cross Eswatini.

Project Objectives

- Create and manage Linux users and groups.
- Organise directories and manage file permissions.
- Configure a web server.
- Develop and execute automated backup scripts.
- Schedule backups using cron.
- Test and maintain the system.

Technologies Used

- Linux (Debian)
- VirtualBox
- Apache Web Server
- Bash scripting
- Cron
- HTML

Skills Demonstrated

- Linux system administration
- User and group management
- File and directory permissions
- Server configuration
- Backup and recovery
- Basic web server administration

Project Purpose

This academic project demonstrates practical knowledge and skills gained in Linux system administration.
